Privacy Policy

youtube-lab is a personal tool used only by its owner.

What data is accessed

With the owner's permission, the tool reads statistics of the owner's own YouTube channel through the YouTube Analytics API and the YouTube Data API, using read-only access. It does not access any other user's account.

How the data is used and stored

The data is used only by the owner to review the performance of their own videos. It is stored only on the owner's own computer. It is not sold, shared, or transferred to anyone.

Revoking access and deletion

Access can be revoked at any time from the Google Account permissions page. After access is revoked, the stored data is deleted within 7 days.
